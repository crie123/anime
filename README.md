#  Anime Collection

Современное настольное приложение для управления и организации коллекции аниме на Windows.

##  Особенности

###  Интерфейс и Тема
- **Динамическое переключение темы** (светлая/темная) с одной кнопкой
- **Полная поддержка локализации** (Русский и Английский языки)
- **Закругленные кнопки** (border-radius: 8px) для современного вида
- **Адаптивный макет** с боковой панелью для деталей

###  Управление коллекцией
- **Добавление аниме** с постером и скриншотами
- **Редактирование** существующих записей
- **Удаление** с подтверждением
- **Поиск** по названию, описанию и тегам
- **Фильтрация** по тегам (и множественный выбор)
- **Сортировка**:
  - По названию (A-Z, Z-A)
  - По дате добавления (новые в начале)

###  Импорт/Экспорт
- **Экспорт** коллекции в JSON формат
- **Импорт** из JSON файлов
- **Массовое редактирование** тегов
- **Массовое удаление** элементов
- **Массовый экспорт** выбранных аниме

###  Обработка изображений
- **Автоматическое создание миниатюр** (thumbnails)
- **Локальное копирование** исходных файлов
- **Кэширование** для быстрой загрузки
- **Карусель скриншотов** для просмотра
- **Портативные относительные пути** - приложение работает из любой папки

###  Персистентность
- **Автосохранение** в локальную базу данных (TinyDB)
- **Запоминание позиции окна** на экране
- **Запоминание настроек** (сортировка, фильтры, язык, тема)
- **Восстановление** при перезагрузке приложения

###  Локализация
- **Русский язык** (полная поддержка)
- **Английский язык** (полная поддержка)
- **Динамическое переключение** без перезагрузки
- **Все UI элементы** переводятся в реальном времени

##  Требования

- **Windows 7+**
- **RAM**: 512 MB минимум
- **Дисковое пространство**: 100 MB для приложения + место для медиафайлов

##  Установка и Запуск

### Из исходного кода

1. **Установите Python 3.8+**
   ```bash
   python --version
   ```

2. **Клонируйте/загрузите проект**
   ```bash
   cd anime
   ```

3. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите приложение**
   ```bash
   python main.py
   ```

### Из исполняемого файла (EXE)

1. **Скачайте** `AnimeCollection.exe` из релизов
2. **Запустите** exe файл
3. **Все готово!** База данных и настройки сохраняются локально

##  Управление

### Основные действия
- **Добавить** - добавить новое аниме в коллекцию
- **Изменить** - отредактировать выбранное аниме
- **Удалить** - удалить выбранное аниме (с подтверждением)
- **Импорт** - импортировать аниме из JSON файла
- **Экспорт** - экспортировать коллекцию в JSON файл

### Поиск и Фильтрация
- **Поле поиска** - ищет по названию, описанию и тегам
- **Фильтр по тегам** - выбирайте несколько тегов для фильтрации
- **Сортировка** - выбирайте порядок вывода (A-Z, Z-A, по дате)

### Переключение Параметров
- **РУ/EN** - переключение между русским и английским языками
- **MOON/SUN** - переключение между темной и светлой темой
- **X** - закрытие приложения

##  Портативность и Перенос Приложения

Приложение использует **относительные пути** для всех изображений, что позволяет переносить его в любое место на диске.

### Как это работает
- ✅ Все пути сохраняются **относительно** exe файла
- ✅ Папки `copies/` и `thumbnails/` всегда рядом с приложением
- ✅ Полная портативность - просто скопируйте папку `anime/` в новое место и запустите

### Переношу приложение на другой компьютер

1. **Если у вас есть старые записи с абсолютными путями** (до обновления):
   ```bash
   python regenerate_paths.py
   ```
   Это конвертирует все абсолютные пути в относительные.

2. **Скопируйте целиком папку `anime/`** (со всеми файлами и папками):
   - `AnimeCollection.exe` (или `main.py`)
   - `anime.db` (база данных)
   - `copies/` (папка с изображениями)
   - `thumbnails/` (папка с кэшем)
   - Остальные файлы

3. **На новом компьютере все будет работать как есть** 

##  Технологический Стек

- **Kivy** - UI фреймворк для кроссплатформенных приложений
- **TinyDB** - легкая встроенная база данных JSON
- **Pillow** - обработка и создание миниатюр изображений
- **PyInstaller** - сборка в исполняемые файлы

##  Разработка

### Добавление новых переводов

Отредактируйте `localization.py`:

```python
TRANSLATIONS = {
    'ru': {
        'key_name': 'Русский текст',
    },
    'en': {
        'key_name': 'English text',
    }
}
```

### Добавление новых UI элементов

1. Добавьте StringProperty в `AnimeApp` класс
2. Обновите `_update_strings()` метод
3. Определите элемент в `anime.kv`
4. Используйте `app.str_element_name` в KV файле

##  Самостоятельная Сборка

Для создания исполняемого файла (.exe) используйте универсальный скрипт сборки:

### Самый простой способ (Рекомендуется)

**Windows:**
1. Откройте папку проекта в проводнике
2. Дважды кликните на `build.bat`
3. Дождитесь завершения сборки
4. Исполняемый файл будет в папке `dist/AnimeCollection.exe`

**Или из командной строки:**
```bash
cd d:\anime
build.bat
```

### Ручная сборка (Альтернатива)

Если `build.bat` не работает, используйте PyInstaller напрямую:

```bash
cd d:\anime
pyinstaller ^
    --onefile ^
    --windowed ^
    --name=AnimeCollection ^
    --add-data="anime.kv:." ^
    --add-data="icons:icons" ^
    --hidden-import=kivy ^
    --hidden-import=pillow ^
    --hidden-import=tinydb ^
    main.py
```

**Что делает build.bat:**
- ✅ Проверяет наличие Python
- ✅ Автоматически устанавливает PyInstaller если его нет
- ✅ Очищает предыдущие сборки
- ✅ Собирает приложение в один exe файл
- ✅ Включает все необходимые ресурсы (иконки, KV файл)
- ✅ Выводит информацию о ходе процесса

### После сборки

- **Исполняемый файл:** `dist/AnimeCollection.exe`
- **Размер:** ~100-150 MB (включая Python и все зависимости)
- **Распространение:** Можете скопировать только `AnimeCollection.exe` на другой компьютер

### Требования для сборки

- Python 3.8+ (установлен и в PATH)
- PyInstaller (установится автоматически через build.bat)
- ~500 MB свободного места на диске
